# Физа — тренажёр по физиологии

Статический сайт для решения вопросов по выбранным темам. Регистрация и сервер не нужны.

## Как работает

1. Выберите темы и сформируйте колоду.
2. Вопросы из стопки «Новые» выдаются в случайном порядке без повторов.
3. Ошибки попадают в отдельную стопку. При верном ответе вопрос удаляется из неё; при неверном остаётся.
4. Статистика считает только первое прохождение: общее число вопросов, прорешано, верно и процент верных среди прорешанных.
5. Прогресс сохраняется в `localStorage` этого браузера. «Завершить и сбросить» удаляет колоду, статистику и выбор тем.

## Запуск локально

Нужен обычный статический сервер, например `python -m http.server 8000`. Откройте `http://localhost:8000/`. Открытие `index.html` через `file://` не загрузит JSON из-за ограничений браузера.

## Публикация на GitHub Pages

Создайте репозиторий GitHub и загрузите всё содержимое этого каталога в корень ветки `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. После публикации сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Пути к файлам относительные, поэтому сайт работает и на адресе репозитория GitHub Pages.
