ФОРМАТ JSON
-----------
Каждый файл — массив объектов следующей структуры:
[
  {
    "id": 1,
    "question": "В состав клеточных мембран входят:",
    "type": "multiple",
    "options": [
      {"id": 1, "text": "фосфолипиды;"},
      {"id": 2, "text": "гликопротеины;"},
      {"id": 3, "text": "транспортные белки;"},
      {"id": 4, "text": "медиаторы."}
    ],
    "correctAnswers": [1, 2, 3],
    "sourcePage": 3
  }
]

Поля:
- id: номер задания в оригинальном сборнике (уникален по всем файлам).
- question: формулировка задания.
- type: single / multiple в зависимости от числа ответов в ключе.
- options: пронумерованные варианты с текстом.
- correctAnswers: массив правильных ID вариантов (нумерация с 1).
- sourcePage: страница исходного PDF (счёт от первой страницы файла).
